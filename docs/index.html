    Cài đặt Firebase

    App kết nối tới project Firebase của bạn để đồng bộ dữ liệu qua Firestore. Cấu hình dưới đây là của project seo-manager-a09c3 bạn đã cung cấp; bạn có thể thay bằng project khác — cấu hình chỉ lưu trong trình duyệt này.

    Điều kiện để đăng nhập chạy được: project đã tạo Firestore Database và bật phương thức đăng nhập Google (Authentication → Sign-in method). Nếu gặp lỗi “unauthorized-domain”, hãy thêm tên miền nơi bạn mở app (ví dụ phantrinh01.github.io) vào Authentication → Settings → Authorized domains.

    Cài đặt Google Search Console

    App đọc dữ liệu thứ hạng trực tiếp từ Search Console bằng chính tài khoản Google của bạn (quyền chỉ-đọc). Google yêu cầu mỗi ứng dụng web có một OAuth Client ID — bạn tạo một lần, miễn phí, trong Google Cloud Console:

    1. Vào Google Cloud Console → tạo hoặc chọn một project → mục APIs & Services → Library, tìm và bật Google Search Console API.
    2. Vào APIs & Services → Credentials → Create Credentials → OAuth client ID, chọn loại Web application.
    3. Ở mục Authorized JavaScript origins, thêm đúng tên miền nơi bạn mở app này — ví dụ https://phantrinh01.github.io (nếu mở app trong Muse thì thêm origin của trang Muse bạn đang dùng).
    4. Bấm Create, sao chép Client ID (dạng ….apps.googleusercontent.com) và dán vào ô dưới đây.

    Client ID chỉ lưu trong trình duyệt này. Token truy cập Google chỉ giữ trong phiên làm việc (hết hạn sau khoảng 1 giờ) và không được lưu lại; app chỉ lưu property bạn đã chọn cùng bảng số liệu lần tải gần nhất để xem lại khi chưa kết nối.
